ORT GenAI benchmark options

Required benchmark arguments
-i <model directory> -b 1 -l 1024 -g 128 -ml 8192 -r 5 -w 1

These are ORT GenAI benchmark arguments, separate from the WebGPU execution-provider settings in genai_config.json. The C++ runner uses -ml 8192; the Python runner uses -m 8192. Both fix the maximum KV-cache capacity at 8K tokens. Historical C++ binaries without -ml are retained with their effective prompt + generation length and are explicitly marked as not supporting an 8K request.

ToolOptionProfile valueDescription
C++ and Python-i / --input_folder<model directory>Selects the ORT GenAI model directory used by the benchmark.
C++ and Python-b / --batch_size1Runs a single sequence per benchmark invocation.
C++ and Python-l / --prompt_lengths1024Uses the fixed 1024-token prompt workload.
C++ and Python-g / --generation_lengths128Generates 128 tokens after prefill.
C++ model_benchmark.exe-ml / --max_length8192Sets the maximum sequence length and KV-cache capacity to 8K when the historical C++ binary supports this option.
Python benchmark.py-m / --max_lengths8192Python-runner equivalent of the C++ -ml 8192 setting.
C++ and Python-r / --repetitions5Collects five measured repetitions.
C++ and Python-w / --warmup1Runs one warmup before measurement.

Scope

This report covers the selected Phi-4 text-only prefill and decode milestones on RTX 5080. Other ORT WebGPU work, including Qualcomm-specific prefill and decode optimizations, Whisper, Phi-4 multimodal, GPT-OSS, and additional model or hardware optimizations, is outside this series and is not represented here.

Method

All measurements run on NVIDIA GeForce RTX 5080. New and rerun measurements use batch 1, prompt 1024, generation 128, max KV cache 8192 (-ml 8192 in C++ or -m 8192 in Python), and 5 measured repetitions after 1 warmup. Historical C++ runners without -ml cannot request 8K and are explicitly labeled with their effective prompt + generation length. The historical series keeps two pinned accuracy-level 4, graph-ready models (fused or separate RoPE). A model-changing milestone uses an archived matched control/candidate experiment; graph capture remains disabled in stored configs and is enabled only on a temporary copy for its measurement.
